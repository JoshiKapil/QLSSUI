RECOMMENDED ORDER

How SuperAdmin sets up onboarding

  1. 01
    Create departments Add only the departments that need department-specific induction. A Default/Common path does not require a department.
  2. 02
    Create every training video Add video URL, description, optional duration and the assignment rules for that video.
  3. 03
    Create questions after each video Each video must have at least one question, at least two options and exactly one correct answer.
  4. 04
    Build the learning path Arrange videos in order. Set required watch percentage, assignment passing percentage and Must Pass rule.
  5. 05
    Preview and publish Only Published paths are used for new employee onboarding. Existing assigned employees keep their saved snapshot even if the master is edited later.
  6. 06
    Assign the employee Go to Employee Assignment, choose Employee + Department + completion days. The system then creates the sequential path automatically.
